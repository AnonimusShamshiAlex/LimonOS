# ТЗ LimonOS

## Цель
Лёгкая собственная ОС для хакеров и любителей железа. Работает на ПК (x86_64) и в VirtualBox,
загружается с флешки, выходит в интернет, ставит программы командами, запускает программы Linux и .exe.

## Части системы
| Имя | Что это |
|---|---|
| Seed | ядро |
| Zest | терминал и оболочка команд |
| Orchard | рабочий стол и окна |
| Slice | текстовый редактор |
| Vine | сетевой стек |
| Grove | менеджер программ из интернета (`grove get имя`) |
| Pulp | слой запуска программ Linux и .exe |

## Уникальность
1. Данные материнской платы напрямую: команды `board` (SMBIOS), `pci`, `acpi`, `juice`.
2. Опознание устройств по PCI-ID и подбор драйвера, готовый профиль VirtualBox.
3. Установка программ из интернета одной командой, с проверкой подписи.
4. Свои короткие команды с русскими именами, набор для проверки собственных сетей.

## Честно про сложность
Этапы 11 и 12 самые тяжёлые. Linux-программы реально запускать через свой слой системных вызовов.
.exe: сначала простые консольные программы, полный Windows недостижим (объём Wine).
«Открыть все файлы» = набор просмотрщиков по форматам.

10. [x] Слияние веток в одну систему (1.0): ai/aikey + калькулятор + новый браузер (CSS, формы, история) + scan, один общий проверенный сетевой стек

11. [x] 1.1 Punk: тема punk/riot/vapor, игры (snake/tetris/pong/2048), RTL8139, прокси для ИИ, укрепление кучи, исправлен grab/%.Ns
12. [x] 1.2: Memoria (VFS в ОЗУ: Desktop/Downloads/Music/Pictures/System), Проводник (GUI), Диспетчер задач (GUI + top/ps/kill),
             Unix-алиасы (ls/cd/pwd/mkdir/cp/mv/rm/cat/free/df/uname/whoami/apt), куча подстраивается под реальное ОЗУ (8–256 МиБ)
13. [ ] ОТКАЗАНО как нереалистичное без многомесячной работы: apt/pip реально ставящий и запускающий nmap/python/git/msfconsole/sqlmap.
        Нужен загрузчик ELF, системные вызовы, libc, интерпретаторы — отдельный проект. lima/apt честно объясняет это и предлагает
        встроенные замены (scan, seal, abacus, ai).
14. [ ] Дальше для реального ПК: проверка на железе (RTL8139, ATA), USB-накопитель (UHCI/EHCI + mass storage), AHCI,
        проверка сертификатов, ISO в BIOS-режиме с USB-флешки, запись на FAT32 (чтобы Memoria переживала выключение)
