# ТЗ LimonOS

## Цель
Лёгкая собственная ОС для хакеров и любителей железа. Работает на ПК (x86_64) и в VirtualBox,
загружается с флешки, выходит в интернет, ставит программы командами, запускает программы Linux и .exe.

## Части системы
| Имя | Что это |
|---|---|
| Seed | ядро |
| Zest | терминал и оболочка команд |
| Orchard | рабочий стол и окна |
| Slice | текстовый редактор |
| Vine | сетевой стек |
| Grove | менеджер программ из интернета (`grove get имя`) |
| Pulp | слой запуска программ Linux и .exe |

## Уникальность
1. Данные материнской платы напрямую: команды `board` (SMBIOS), `pci`, `acpi`, `juice`.
2. Опознание устройств по PCI-ID и подбор драйвера, готовый профиль VirtualBox.
3. Установка программ из интернета одной командой, с проверкой подписи.
4. Свои короткие команды с русскими именами, набор для проверки собственных сетей.

## Этапы
1. [x] Загрузка, графика, консоль
2. [x] Шрифт, терминал
3. [x] Прерывания, клавиатура, мышь, рабочий стол, команды
4. [x] Память: страницы, куча, kmalloc; PCI; сеть до DNS и ping (e1000)
5. [ ] Железо платы: PCI, ACPI, SMBIOS, команды board/pci/acpi
6. [ ] Процессы, планировщик, режим пользователя, системные вызовы
7. [ ] Диск, VFS, FAT32, файловые команды, редактор Slice
8. [x] Сеть: e1000, ARP, IP, DHCP, DNS, ping (сделано вместе с этапом 4)
9. [x] TCP, HTTP, Citrus-браузер, lima (менеджер пакетов) — TLS ещё не сделан
10. [~] Lima (бывший Grove) умеет качать README пакетов; полноценная установка и проверка подписи — после TLS
11. [ ] Запуск программ Linux (ELF + системные вызовы)
12. [ ] Запуск .exe (PE + часть WinAPI), просмотрщики файлов
13. [ ] Набор для проверки своих сетей, USB, установщик, тест на настоящем ПК

## Честно про сложность
Этапы 11 и 12 самые тяжёлые. Linux-программы реально запускать через свой слой системных вызовов.
.exe: сначала простые консольные программы, полный Windows недостижим (объём Wine).
«Открыть все файлы» = набор просмотрщиков по форматам.
