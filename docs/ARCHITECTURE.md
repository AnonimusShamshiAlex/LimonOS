# LimonOS: чертёж системы (архитектура)

Цель: лёгкая ОС с терминалом, своими командами и простым графическим интерфейсом,
которая работает напрямую с железом, выходит в интернет, ставит программы по команде
и запускается в VirtualBox и на реальном ПК. Уклон: инструменты для изучения сетей и
безопасности (в своей лаборатории и в своих сетях).

## Схема слоёв

```
 ┌──────────────────────────────────────────────────────────────────────┐
 │  ПОЛЬЗОВАТЕЛЬ                                                        │
 ├───────────────────────────────┬──────────────────────────────────────┤
 │  РАБОЧИЙ СТОЛ (desktop.c)     │  ТЕРМИНАЛ (term.c, shell.c)          │
 │  окна, панель, меню, значки   │  команды: zest, peel, juice, ...     │
 ├───────────────────────────────┴──────────────────────────────────────┤
 │  ПРОГРАММЫ                                                           │
 │  редактор │ файловый менеджер │ сетевые утилиты │ пакетный менеджер  │
 ├──────────────────────────────────────────────────────────────────────┤
 │  СЛОЙ СОВМЕСТИМОСТИ  (Linux ELF → затем Windows PE/.exe)             │
 ├──────────────────────────────────────────────────────────────────────┤
 │  СИСТЕМНЫЕ ВЫЗОВЫ (syscall) и режим пользователя (ring 3)            │
 ├──────────────────────────────────────────────────────────────────────┤
 │  ЯДРО                                                                │
 │  планировщик │ память (PMM/VMM/heap) │ VFS │ сеть TCP/IP │ ELF/PE    │
 ├──────────────────────────────────────────────────────────────────────┤
 │  ДРАЙВЕРЫ                                                            │
 │  PS/2, USB │ PCI │ ACPI/SMBIOS │ диск AHCI/NVMe │ сеть e1000/virtio  │
 │  видео (framebuffer) │ таймер, RTC                                   │
 ├──────────────────────────────────────────────────────────────────────┤
 │  ЖЕЛЕЗО: материнская плата, процессор, память, диск, сетевая карта   │
 └──────────────────────────────────────────────────────────────────────┘
        Загрузчик Limine (BIOS/UEFI) передаёт ядру экран и карту памяти
```

## Что уже есть (версия 0.3)
Загрузчик Limine, GDT/IDT/PIC, таймер, RTC, PS/2 клавиатура и мышь, framebuffer-графика
с двойной буферизацией, шрифт с русским, рабочий стол с окнами, терминал, 16 команд,
CPUID, карта памяти.

## Дорожная карта

| Этап | Что делаем | Зачем |
|---|---|---|
| 4 | Менеджер памяти: физические страницы, страничная память, kmalloc | основа для всего остального |
| 5 | PCI + ACPI + SMBIOS: список устройств, модель материнской платы, BIOS | "работает с материнской платой" |
| 6 | Задачи, планировщик, системные вызовы, режим пользователя | запуск программ |
| 7 | Диск AHCI + VFS + FAT32/ext2 | файлы, установка |
| 8 | Сеть: драйвер e1000 (по умолчанию в VirtualBox), ARP, IPv4, ICMP, UDP, DHCP, DNS, TCP, HTTP | интернет |
| 9 | Загрузчик ELF, затем слой Linux-системных вызовов | запуск Linux-программ |
| 10 | Пакетный менеджер lpkg: скачивание программ по HTTP(S) | "установка из интернета" |
| 11 | Слой Windows (PE/.exe), начиная с простых консольных программ | запуск .exe |
| 12 | Редактор, файловый менеджер, просмотрщики файлов | "открывать все виды файлов" |

Честные оценки: этапы 4-8 реалистичны по одному за несколько сессий. Этап 9 (Linux) возможен
для статических программ, динамические требуют ещё и загрузчик библиотек. Этап 11 (.exe) самый
тяжёлый: для настоящей совместимости нужен целый Wine-подобный слой, поэтому идём от простого.
HTTPS требует TLS (свой или портированная библиотека), это отдельная большая задача.

## Планируемые команды (уникальные имена)

| Команда | Что делает | Этап |
|---|---|---|
| board | модель материнской платы, BIOS, версия (SMBIOS) | 5 |
| bus | список PCI-устройств | 5 |
| vine | сетевые интерфейсы, IP, шлюз | 8 |
| splash | ping | 8 |
| lookup | DNS-запрос | 8 |
| grab | скачать файл по HTTP | 8 |
| grove | карта хостов своей подсети (ARP) | 8 |
| sieve | сканер портов своих хостов | 8 |
| ear | просмотр пакетов в своей сети (sniffer) | 8 |
| bones | hex-просмотр файла | 7 |
| grind | хеши файлов | 7 |
| crate | установка программ из интернета (lpkg) | 10 |

Сетевые и "хакерские" инструменты задуманы как учебные и диагностические: для своих компьютеров,
виртуальных лабораторий и сетей, на которые есть разрешение.

## Запуск в VirtualBox
Тип: Other/Unknown (64-bit), 256 МБ+ памяти, ISO в оптический привод, сеть: Intel PRO/1000 MT
Desktop (e1000), NAT. Для загрузки через UEFI включить EFI в настройках системы.
